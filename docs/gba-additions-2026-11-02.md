# Game Boy Advance and catalogue additions

Added eight-device routing with nine GBA titles, five new PS2 titles and Harvest Moon: Magical Melody on Wii, as selected by the owner. Existing Resident Evil 4 (Biohazard 4) remains under its original key, without duplication or local-storage migration.

GBA silhouette is an original SVG drawing of the horizontal AGB-001 layout, following Nintendo hardware documentation: https://www.nintendo.com/en-gb/Hardware/Nintendo-History/Game-Boy-Advance/Game-Boy-Advance-627139.html
Harvest Moon platform verification: https://www.esrb.org/ratings/20912/harvest-moon-magical-melody/

New catalogue records preserve separate game-information and cover-source links. External artwork is not embedded into SVG or bundled into page code. Original user data and keys remain unchanged.
